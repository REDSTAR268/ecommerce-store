# 🛍️ ShopSphere – E-commerce Storefront

Welcome to **ShopSphere**, a modern and responsive e-commerce storefront built with React and Vite.

ShopSphere provides a clean shopping interface where users can explore products, search for items, filter categories, view product details, and manage their shopping cart.

## 🌐 Live Demo

**Visit ShopSphere:**  
https://ecommerce-store-5nn80gqgx-bluestar-278.vercel.app

## 📌 Project Overview

ShopSphere is a frontend e-commerce web application developed as part of an Advanced React Practical assignment.

The project focuses on building a functional and user-friendly shopping experience using React components, state management, and modern CSS styling.

## ✨ Features

- 🏠 **Home Page** – Welcome section, promotional banner, categories, and featured products.
- 🛍️ **Products Page** – Browse the available product collection.
- 🔎 **Product Search** – Search for products by name.
- 🗂️ **Category Filtering** – Filter products by category.
- ↕️ **Price Sorting** – Organize products by price.
- 📦 **Product Details** – View individual product information.
- 🛒 **Shopping Cart** – Add products and manage cart quantities.
- 💳 **Checkout Page** – Shopping checkout interface.
- 🌙 **Dark and Light Mode** – Switch between different visual themes.
- 📱 **Responsive Design** – Designed to provide a user-friendly experience across different screen sizes.

## 🚀 Getting Started

Follow these instructions to run ShopSphere locally.

### 1. Clone the Repository

```bash
git clone https://github.com/REDSTAR268/ecommerce-store.git
```

### 2. Open the Project Folder

```bash
cd ecommerce-store
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### 5. Build for Production

```bash
npm run build
```
